About Prioday

A prioritized todo list for repetitive chores and tasks

For organizing chores and tasks on daily, weekly, monthly, or yearly schedules.

Header Section:

  • Left icon (⚙️): Click to access settings where you can change themes and animation preferences
  • Center title: Shows "Prioday" followed by today's date
  • Right icon (+): Click to create a new todo item

Main Todo List:

The page displays all your recurring tasks in a smart, prioritized order:

Each todo item shows:

  • Left column: When you last completed this task ("Today", "Yesterday", "3 days ago", etc.)
  • Center: The task name and how often it needs to be done (daily, weekly, monthly, etc.)
  • Right column: When it's due next ("Today", "Tomorrow", "in 2 days", etc.)
  • Checkmark button: Click to mark the task as completed for today

Color-coded priority system:

  • Blue highlight: Tasks due today (highest priority)
  • Red highlight: Overdue tasks that should have been done already
  • Green highlight: Tasks you've already completed today
  • No highlight: Future tasks not yet due

How it works:

  1. Add recurring tasks (like "water plants every 3 days" or "pay rent monthly")
  2. The app automatically calculates when each task is due based on when you last did it
  3. Tasks are sorted by urgency - overdue and due-today items appear at the top
  4. Click the checkmark when you complete a task
  5. The app remembers everything locally in your browser

Perfect for:

  • Household chores and maintenance
  • Health routines and habits
  • Bill payments and recurring responsibilities
  • Any task that needs to be done repeatedly on a schedule

Use Cases:

  • Do you need to be reminded to do that thing every 5 days, 2 weeks, or 3 months?
  • Ever forget the last time you vacuumed?
  • Are you sure you watered the plants yesterday or was it the day before yesterday?
  • Not sure if you finished wordle, duolingo, the daily chess puzzle today?
  • Do you need a reminder to pay that bill this month?
  • Did you filter that mead you were brewing on the 19th or the 29th of last month?

Solution:

  • Set a frequency for how often a task needs to be done
  • Tasks that need to be done today will be at the top of the todo list (colored blue)
  • Tasks that do not need to be done until a future date are further down the list
  • Tasks that should have been done yesterday will be shown in red
  • Easily see the last time a task was done and the days before a task needs to be done again
